```bash
python3 docs/verification/add-v02-probe.py
```

### 价格候选与采集槽冲突

- **Alpaca Basic** 的官方 FAQ 支持查询截至至少 15 分钟前的历史 SIP 数据，历史 bars 接口支持多代码，时间上与收盘后首槽相容。必须显式选 SIP、核对合格的常规收盘定义及拆股调整，不能直接把任意日线或最后一分钟成交价当作官方收盘。当前没有凭证，未做认证、逐股覆盖或价格一致性测试。[Alpaca FAQ](https://docs.alpaca.markets/us/docs/market-data-faq) · [历史 bars](https://docs.alpaca.markets/reference/stockbars)
- **Massive Basic** 的官方说明显示，前一交易日 REST 数据最早在次日纽约 00:00 可取。个股日结接口区分收盘与盘前盘后，批量行情的 `close` 还需与个股日结样例核对。常规日三个槽位为纽约 17:30、19:00、22:00，均早于该来源开放时间。以 11-09 为例，三个槽位折算巴黎时间为 11-09 23:30、11-10 01:00、04:00。Massive 开放时间为巴黎 06:00，仍早于 18:00 截止。若选择该源，必须明确启用截止前的次日补采路径或标准导入。单靠原三个槽位无法验证其日更，已有合格数据才可计为通过。[Massive Basic 可用时间](https://massive.com/knowledge-base/article/on-the-free-basic-plan-when-can-i-pull-the-previous-trading-days-data) · [个股日结字段](https://massive.com/docs/rest/stocks/aggregates/daily-ticker-summary)

软件层正式验收需交付可运行的导入、计算、归档和看板，再执行 §11 的公式、契约、浏览器、性能及恢复测试。真实 TTM 和 FY1 分别验收，先共同通过同日权重和全量常规收盘价。保留数据源实测与软件验证两份证据。
