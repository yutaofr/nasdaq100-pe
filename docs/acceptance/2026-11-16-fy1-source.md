## 仍然缺失的证券

| 口径 | 原因 | 证券 |
|---|---|---|
| FY1 | 发行人不是只以 USD 报告，预测币种无从核对 | ASML、CCEP、FER、PDD |
| FY1/TTM | 无官方收盘价 | DASH |
| TTM | 外国发行人，companyfacts 无近期 USD 季度净利润（或只有年报，超过 180 天） | ASML、CCEP、FER、PDD、NBIS、TRI、ARM |
| TTM | 上市不足一个完整财年 | SPCX、HONA |
| TTM | 净利润 ÷ 稀释股数与已报告稀释 EPS 不符 | INTC、KDP |
| TTM | 无近期稀释股数标签 | BKR、TTWO |
| TTM | companyfacts 最新期仍为 2026-03-31（重新获取后未变），超过 180 天 | AEP、EXC |
| TTM | 人工裁定 | HON |

SPCX 权重大（替代篮子中约 4.4%），在其首份年报之前 TTM 覆盖率离 90% 门槛不远；若真实权重下跌破门槛，首页 TTM 会按规则留空。
